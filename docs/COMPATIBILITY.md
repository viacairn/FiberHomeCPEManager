# 兼容性

应用支持 Apple Silicon 与 macOS 14+。界面保留“烽火 CPE 设备，RP0106+”适配范围说明；协议实现的验证范围如下。

| 设备 / 固件 | 状态 |
| --- | --- |
| LG6851F / RP0112 | 已验证登录、状态读取、设备列表、短信与主要配置接口 |
| LG6851F / RP0106–RP0111 | 尚未逐版本验证 |
| 其他 FiberHome 型号 | 尚未适配，不应据此推断兼容 |

## 协议边界

- 制式根据 LTE / NR 实际接入字段判定，`WorkMode` 是组网模式，不能直接当作制式。
- WAN 连接状态用于判定上行可用性；SIM 或注册标志不能单独作为断网依据。
- LTE 未接入时忽略其残留 PCI、信号与零值；未知数据保留为空。
- 设备只显示活动条目；接入类型优先使用接口信息，无法确定时显示未知。
- 设备类型与图标为通用推断，允许用户覆盖，不把固件分类视为可靠设备识别。
- 普通心跳不等于续期；客户端分别检查认证并刷新无操作期限。
- 飞行模式、DDNS 解析结果和端口映射外部可达性不作为全环境兼容承诺。
- 认证失效返回登录页；不支持的可选保活接口不阻止受保护状态读取。

接口、字段与写入限制见 [Web API](protocol/WEB-API.md)、[高级控制](protocol/ADVANCED-CONTROLS.md) 和 [会话处理](protocol/SESSIONS.md)。
