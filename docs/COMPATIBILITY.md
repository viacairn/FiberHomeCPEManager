# 兼容性

## 平台

| 项目 | 要求 |
| --- | --- |
| 处理器 | Apple Silicon |
| 系统 | macOS 14 及以上 |
| 开发 | Swift 6 与匹配的 macOS SDK |
| 界面增强 | 新版 macOS 使用系统玻璃与滚动边缘，旧版保留材质回退 |

## 设备

| 设备 / 固件 | 验证状态 |
| --- | --- |
| LG6851F / RP0112 | 已适配登录、状态、设备、短信及主要配置接口 |
| LG6851F / RP0106–RP0111 | 未逐版本验证，不能据此保证全部功能可用 |
| 其他 FiberHome CPE | 尚未适配 |

About 的 RP0106+ 文案表示目标适配范围，不等于所有版本均已验证。未知型号会在发送登录凭据前停止连接。

## 功能边界

- 蜂窝优先、以太网优先与 MLO 配置仍为占位，状态见 README 的未完成表格。
- DDNS 配置保存成功不代表公网解析已经生效；端口映射保存成功不代表外网能够穿透运营商网络。
- 设备类型属于通用推断，可以手动指定图标；未知分类保留为未知。
- 不同固件缺少的指标显示为 `—`，不使用其他设备的样本值填充。
- 设备的管理会话可能互相挤占；认证失效后必须重新登录。
