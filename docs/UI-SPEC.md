# 界面与交互

本文约定当前页面的布局、状态与交互，供维护和回归验证使用。具体尺寸与颜色以 `Sources/FHCPEMUI/Theme.swift` 为准，菜单栏几何以 `MenuBarGeometry.swift` 为准。新增功能沿用现有材质、胶囊控件和页面结构。

## 面板与导航

- 内容画布为 350 × 606 pt；保留 NSPopover 原生背景扩展，不扣减系统箭头边距。
- 除 About 外显示居中的 FiberHome CPE Manager 标题，标题与内容采用相同前景色。
- 滚动内容经过标题区域时渐变遮挡，底部导航为悬浮胶囊，内容不被硬切割。
- 概览、设备、控制、短信共用底部导航；详情页在画布内返回，不改变面板尺寸。
- 控制页首屏外板块延迟布局；首次连接可用即预读移动网络状态。
- 页面切换不使用隐式动画。只允许明确需要的局部反馈，避免整页重排与过渡开销。
- 内容不产生横向滚动；只有超过可用宽度的短信号码允许在标题自身区域内横向滚动。

## 数据与连接

- 登录后每 3 秒采样；关闭弹窗仍持续运行。网络请求未完成时不叠加采样。
- 每 30 秒检查认证并续期无操作期限；认证失效时使用内存凭据静默重试一次，失败才返回登录页。
- 瞬断时隐藏实时读数，蜂窝参数、速度、流量等显示缺失值；保留未发送短信和正在编辑的网络表单。
- 正常获取的零速率显示为 0，不能把断线伪装成零速率。
- 仅在静默重新登录失败后返回登录页。右键菜单保留用户主动触发的重新登录。
- 断线前发出的请求通过连接代次与数据代次校验，晚到结果不得回填旧数据。

## 登录与密码

- 账号密码由用户输入，保存密码为可选系统钥匙串功能。
- 密码使用 SwiftUI SecureField / TextField；输入与提交时自动将全角 ASCII 字符归一化为半角。
- 粘贴、回车提交与可见密码模式使用相同归一化与验证规则。
- 钥匙串使用标准 SecItem API 与静默认证上下文；一次失败不会永久禁止后续访问。

## 概览与蜂窝详情

- 保留现有运营商卡片、速率和流量模块风格，动态信号图标随读取结果更新。
- 蜂窝信息一排四项；QCI 与上下行签约速率维持既定次序，RSSI 与 RSRP 等提供进度指示。
- 蜂窝详情入口为“更多”；基站与小区信息共用一页，避免重复展示概览内容。
- 邻区 RSRP / SINR 指标采用固定列宽，负号与位数变化不改变对齐。

## 设备

- 搜索框与接入类型胶囊弹出菜单同行；筛选不额外占用一整排。
- 设备图标按通用类别推断，无法确定时显示未知；允许手动指定或恢复自动识别。
- 设备自定义图标按规范化 MAC 存取；没有 MAC 时使用 device.id。
- 同名但不同 MAC 的设备不继承图标；无 MAC 的设备换 IP 后不自动继承。
- 设备设置使用原生菜单；菜单和编辑浮层内点击不会误关主面板。
- 静态 IP 保留 IPv4 与 MAC 基础校验，固件裁决地址冲突；写入或解除后刷新一次列表。已绑定设备显示标识，菜单提供复制 IP / MAC。

## 控制

板块顺序为移动网络、上网运行模式、网络服务、Wi-Fi 广播、定时重启、硬件控制。

- 5G NR 外置天线与风扇使用统一弹出选择样式；天线包含“关闭”选项。
- 风扇为标准、静音、性能；LED 与风扇不附加冗长描述。
- Wi-Fi 辅助网络使用“访客 Wi-Fi”文案。
- 定时重启的时间编辑同行；立即重启需二次确认，等待设备恢复后自动重连。
- 五个上行模式采用 3+2 分层布局；两种优先模式保留灰置，MLO 卡片保留占位标签。
- 小区锁定与频段锁定互斥；直接关闭另一模式并写入目标配置，完成后刷新一次。频段通过多选胶囊选择。
- DDNS、端口映射等写操作检查固件成功回执后刷新一次列表，不再重复扫描比对。端口映射支持编辑、设备选 IP 和单端口自动填充。
- 控制页设置每 3 秒静默对齐，不切换忙碌状态、不替换相等值，避免开关闪烁。

## 短信

- 会话、号码与正文只在内存中；瞬断保留草稿，仅主动断开或切换路由器时清理。
- 进入页面立即读取；可见页面每 3 秒兜底同步，接收计数改变后立即触发完整读取。
- 读取与发送期间到来的请求合并为后续读取，不丢弃发送完成或新短信事件。
- 发送成功立即读取，随后延迟核对；临时已发送气泡与设备结果合并，避免消息闪退。
- 可见会话自动已读；旧读取响应不能恢复已清除的未读角标，新收到的短信仍正常识别。
- 号码相对页面自适应居中，最大预留 220 pt；超宽时仅号码区域可滚动。
- 底部日期、最后一条消息和回复框保持独立布局，首次进入也不重叠。

## 提醒、菜单与 About

- 成功、失败、断线等瞬时提醒统一为覆盖式气泡，各自 10 秒消失，并提供关闭按钮。
- 提醒不挤占页面内容；持续状态由缺失值、空态和登录页表达。
- 菜单栏图标保持固定宽度并使用系统模板图像；相同读数不重复绘制位图。
- 右键保留刷新、重新登录、显示样式、清除已保存密码、关于与“退出应用”。
- About 从 Bundle 读取版本，支持说明为“烽火 CPE 设备，RP0106+”；适配验证范围见兼容性文档。
- Esc 优先关闭当前菜单或编辑器，再返回上一页或关闭面板；⌘R 刷新，⌘Q 退出应用。
