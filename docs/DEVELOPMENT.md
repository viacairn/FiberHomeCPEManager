# 开发与打包

## 项目结构

| 路径 | 职责 |
| --- | --- |
| `Sources/FHCPECore` | 设备会话、协议适配、数据模型与配置服务 |
| `Sources/FHCPEMUI` | SwiftUI 页面、原生控件桥接与主题 |
| `Sources/FHCPEM` | 菜单栏入口、生命周期和页面状态协调 |
| `Sources/FHCPEMWidget` | 桌面磁贴 |
| `Sources/UIRender` | 使用模拟数据的文档截图与布局验证 |
| `Sources/FHCPEMProbe` | 显式调用的开发探针 |
| `Tests` | 本地模拟服务与回归测试 |
| `script` | 构建、打包、隐私和界面检查 |

内部协议笔记单独放在本地 `docs/protocol/`。该目录不提交、不导出到 Release，公开文档不依赖其中的链接。

## 构建

```sh
./script/build_and_run.sh --build-only
./script/build_and_run.sh
./script/build_dmg.sh
```

脚本选择匹配的 SDK，将缓存放入构建目录。Release 在隔离目录中构建，移除设备测试环境变量，映射编译路径并剥离调试符号。主程序与 Widget 分别签名，再检查整体签名；开发探针和测试源码不进入应用包。

## 版本

主程序与 Widget 的 `CFBundleShortVersionString`、`CFBundleVersion` 必须一致，About 从 Bundle 读取版本。同步更新 README 的当前版本与打包文件名说明。

## 构建日志

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| `error:` 或非零退出码 | 编译、签名或打包失败 | 必须修复，不能当作成功发布 |
| 隐私检查出现 finding | 公开内容含排除项或敏感信息 | 阻止打包并清理工作区及历史 |
| 钥匙串 API 弃用警告 | 旧登录钥匙串兼容路径使用历史 API | 已移除重复旧 UI 参数，使用现代认证上下文；仍保留防弹窗兼容保护，不盲目删除 |
| CLT `search path ... not found` | 当前 Swift Build 为 CLT 注入不存在的开发框架目录 | 构建成功时不代表缺少运行依赖；检查实际链接与应用签名，不创建伪目录或全局屏蔽警告 |
| `replacing existing signature` | 对构建产物重新签名 | 正常，随后必须通过 codesign 验证 |
| 镜像工具弃用提示 | 系统迁移了镜像创建接口 | 新系统选用受支持接口，旧系统保留兼容路径 |
| `Checksumming`、CRC 与 `VALID` | 镜像完整性验证进度和结果 | 正常；验证失败则阻止输出完成 |

## 界面性能

页面切换不添加整页动画。控制页延迟构建首屏外板块；连接首次可用时预读移动网络状态，避免第一次进入才请求。设置与移动网络相等值不重复发布，后台读取不切换用户写入的忙碌状态。

保持视图尺寸和操作逻辑稳定。比较修改前后时区分布局、网络等待与截图成本，使用相同模拟数据，并在原生界面补充检查。

## 文档图片

`docs/images/` 只保留选定的模拟页面 PNG。渲染器与应用共用承载控制器，保持安全区和滚动规则一致。重新生成后核对外观、尺寸、横向溢出与 PNG 元数据，再运行隐私检查。不要从开发设备屏幕截取真实信息替换示例图。
