# FHCPEM v6 · 视觉与交互规格

日期：2026-10-17。范围：完整视觉方案与落地约束，尚未实施产品代码变更。

## 1. 布局与材质

常规概览、设备、短信、控制和连接面板以约 340 pt 宽为设计目标；数据密集的蜂窝详情使用约 600 pt 宽的二级面板。高度约 560 pt 和 650 pt，长列表或正文滚动查看。最终尺寸以系统字体、可读性和无裁切为准。

使用原生 macOS 的中性材质、石墨色文字、细致的数字层级和少量系统蓝。玻璃主要用于导航及短暂控制层。浅色与深色共享语义颜色。所有主页面不作横向分割线，使用间距、字重和纵向对齐关系分组。

连接后的主页面以概览、设备、控制、短信四项导航为首行，不再添加应用 Logo、型号、LAN IP 与状态的固定顶栏。型号紧邻底部设置图标，连接状态在右下。设置与首次连接页面中的地址输入框保留，便于编辑 LAN 地址。

## 2. 网络行与状态语义

当前蜂窝制式、频段与信号柱处于同一行，例为信号柱 / 5G / N70/B3。只展示当前活动蜂窝网络的一组指标，不并列宣称 4G 与 5G 同时在线。N70/B3 为用户指定示例，不代表已验证该型号支持此组合。

右侧仅显示一盏状态灯和当前上行模式，不再写信号良好等描述。四种模式为蜂窝上行、宽带上行、双网聚合、主被模式，每次显示当前一种。

绿灯仅用于已有新鲜设备证据确认当前上行可用；红灯表示不可用或当前无法确认可用。速率为零或信号较弱不能单独用来判定故障。灯色表达可用性，信号柱表达信号强度，两者独立。

设备连接状态和上行可用性也相互独立：应用仍可连接到 CPE，而该 CPE 的外网暂时不可用。悬停及辅助功能文案提供可用性与原因，不能只依赖颜色传递语义。无法确认当前数据时不保留假实时数值。

## 3. 数值与单位

四项主数据固定位置：

| 位置 | 指标 | 数值例 | 单位 |
| --- | --- | --- | --- |
| 左上 | 上行速率 | 12.8 | Mbps |
| 左下 | 下行速率 | 102 | Mbps |
| 右上 | 今日流量 | 9.42 | GB |
| 右下 | 本月流量 | 126.8 | GB |

单位紧随数字右上角，字号明显小于数字。指标说明置于数字下方，数字与说明沿栏位中轴对齐。不使用上下行箭头，不把说明放在左侧或上方。

速率格式化以 bit/s 为源语义。如果设备明确提供的是 byte/s，则乘 8；若源单位不同，必须先按证据转换，不靠字段名猜单位。使用十进制速率前缀：

- 小于 1,000,000 bit/s 使用 Kbps，数值除以 1,000。
- 从 1,000,000 到不足 1,000,000,000 bit/s 使用 Mbps，数值除以 1,000,000。
- 从 1,000,000,000 bit/s 起使用 Gbps，数值除以 1,000,000,000。
- 数值最多保留三位有效数字，舍入到边界时提升单位，避免显示 1000 Kbps 之类较宽字符串。
- 已连接且明确测得零值可显示 0 Kbps；未采样、离线或无证据值显示“—”，不能伪造零值。

示例：原 1.6 MB/s 换算为 12.8 Mbps；原 12.8 MB/s 换算为 102.4 Mbps，三位有效数字显示 102 Mbps。不是只把 MB/s 字样换成 Mbps。

流量是累计字节量，不乘 8、不改写为 Mbps。今日 / 本月仅在设备明确返回对应统计周期时使用，否则显示设备累计。

## 4. 菜单栏宽度与刷新

菜单栏项默认显示信号柱和下行速率，例如 102 Mbps。四根递增信号柱有 0–4 根有效柱，外框尺寸保持稳定。无 Wi-Fi 图标、路由器图标或速率箭头。

信号柱、间隔和数字文本的布局目标约 80–90 pt，最终按系统字体及内边距计算。使用等宽数字、最多三位有效数字、可预留的稳定宽度，避免读数变化推动相邻菜单栏项目。可在设置中选择信号与速率或仅信号。

正常目标周期为每秒一次状态读取和 UI 更新，弹窗打开与关闭时均如此。单批请求在途，不累积并行请求；设备响应慢时按实际采样间隔计算速率。断网、休眠和认证失效进入明确状态，恢复后再读取。

一秒刷新不等于每秒执行完整基站扫描，不自动重发短信或无线控制命令，也不每秒重读全部短信正文。界面不提供常规手动刷新按钮，不显示更新时间或倒计时。

## 5. 在线设备

使用单一、不分组的列表。左侧图标，中间名称与下一行 IP，右侧固定列显示有线接入、5G Wi-Fi、2.4G Wi-Fi之一，最右是详情披露箭头。

搜索框和类型下拉在同一排。下拉单选全部设备、有线接入、5G Wi-Fi、2.4G Wi-Fi。搜索与类型筛选共同作用，结果为空时显示明确空态。默认列表显示总数；筛选后显示筛选数与总数，例“4 台 · 共 9 台”。

接入类型依据设备返回的接口与无线频段信息，不通过设备名称猜测。5G Wi-Fi 指 5 GHz 无线接入，不能与 5G 蜂窝网络混淆。未知接入信息保留未知语义。

## 6. 蜂窝详情与小区锁定

概览保留九项高密度摘要：RSRP、RSRQ、SINR、PCI、NR-ARFCN、带宽、TAC、NCI、PLMN。更多设备信息进入宽面板。

技术指标按信号测量、网络与小区、射频与链路分组，容纳 RSSI、SSB 索引、发射功率、NCGI、gNB ID、上下行频率、SCS、MIMO、CQI、TA 等设备能提供的字段。未知值使用“—”，不把标准中定义的字段当作设备已经提供的字段。

基站与小区页展示设备返回的全部可发现结果，滚动及筛选不丢弃结果。服务中、邻区、未接入分开表达，仅服务中代表当前活动连接。扫描返回的小区记录不能直接等同于附近全部物理基站，分组聚合需要可靠标识。

小区锁定仅从该详情页发起，目标可为当前服务小区或明确选中的列表小区。确认网络类型、频段、信道和 PCI 等目标字段，缺少必要值或接口未适配时禁用。提交前显示具体变更摘要，继续遵循自动、锁频段、锁小区互斥，不把它们做成独立开关。

## 7. 设备控制

通用控制页保留频段设置、风扇策略、重启；不再放锁小区选择器或操作。风扇仅出现已验证设备支持的模式与范围。

未适配写接口保持禁用。重启确认说明短暂断网；不因断线就宣称已重启成功。超时写请求不自动重放，结果不确定时保留待确认语义。

## 8. 短信流程

短信默认进入收件箱。收件箱可阅读正文，提供发件箱入口和撰写入口。发件箱展示设备返回的发送记录或空态，不生成假的成功历史。新短信编辑器包含收件人、正文和字符计数，具体长度限制取决于已验证协议，不预先猜分段限制。

发送前确认号码与正文；失败保留内存草稿，不自动重试发送。界面图中的通知均为通用示例，不包含私人短信。适配中只禁用依赖未验证设备能力的动作，不能把图稿当作功能已经可用。

## 9. 设置与首次连接

设置集中提供管理地址、账号、密码、记住连接、重新连接、清除已保存连接和菜单栏显示内容。凭据只按用户选择保存到系统钥匙串，默认不勾选记住连接。地址和型号不回到主页面顶部。

首次连接没有已连接状态或伪实时速率，菜单栏使用无有效信号柱和“—”。未知型号显示待连接；连接后才能展示设备确认的身份与状态。

## 10. 交付与验证边界

本版 6 张图包含 15 个主要页面 / 状态，以及 1 张共享组件规范。原始扁平应用图标随本版保存。所有图、规格和原始提示词集中在当前目录，前版仅保留历史参考。

生成方式为内置 image_gen。图稿经过人工视觉检查并核对保存结果；数值、地址、型号固件及扫描结果是示例。未改应用代码，未执行新的真机扫描、重启、锁定或短信操作。

视觉参考与蜂窝字段来源记录见项目历史设计资料；本版不据此新增任何设备兼容性或协议完成声明。
