# 隐私与本地数据

## 应用数据

| 数据 | 保存方式 | 清除时机 |
| --- | --- | --- |
| 登录密码与连接信息 | 用户选择保存时进入系统钥匙串 | 右键菜单清除已保存密码 |
| Cookie、会话令牌 | 当前进程内存 | 显式断开、注销或退出 |
| 短信、设备列表、蜂窝详情 | 内存 | 主动断开或换连接时清空；瞬断保留内存草稿 |
| 手动设备图标与显示偏好 | 本地应用偏好设置 | 恢复自动识别或清除应用数据 |
| 桌面磁贴快照 | App Group，仅含汇总状态 | 连接状态变化时替换，不含短信、凭据、设备名称或地址 |

应用不使用明文密码文件，不将短信或原始 API 报文持久化。读取钥匙串不主动弹出后台认证窗口，失败后允许手动输入。

## 仓库与文档

公开截图由 `UIRender` 使用模拟数据生成。真实截图、测试凭据、原始报文、抓包和开发设备信息不提交。

逆向协议笔记位于本地 `docs/protocol/`，整个目录被本地 Git 排除规则排除，也不进入发布源码快照与 DMG。历史版本同样需要排除，不能只依赖工作区的忽略规则。

`.gitignore` 按项目约定仅在本地保留；`script/package_release.py --configure-only` 会幂等配置 `.git/info/exclude`。

## 检查

```sh
python3 script/check_privacy.py --history
git ls-files .gitignore docs/protocol
```

第二条应无输出。扫描覆盖工作区、全部 Git 对象、二进制字符串及 PNG/ICNS 压缩文本元数据；强制跟踪本地协议文档也会被阻止。清理时可以临时传入仓库外的精确清单，核查后删除。

Release 只从公开文件构建，并检查实际挂载后的 DMG。固件协议使用的固定材料不是个人会话密钥，发布时校验其与源码资源一致。
